# Курсовий проєкт з розробки веб-інтерфейсів 💍

Практична реалізація завдання: створення багатосторінкового адаптивного веб-ресурсу для весільного заходу **"Геннадій & Жасмин"**.

## 🌐 Живе посилання на проєкт
* **Проєкт на GitHub Pages:** [Відкрити весільний сайт](https://denysgimg.github.io/denysproject/)

---

## 📈 Календарний план та етапи розробки
1. **Аналітичний етап:** Дослідження аналогів веб-запрошень, розробка архітектури та карти взаємодії користувача з сайтом.
2. **Підготовка ресурсів:** Оптимізація медіа-файлів (фото, відео-прев'ю), вибір шрифтових пар та колірної палітри.
3. **Етап верстки:** Написання семантичної та повністю адаптивної структури (проєкт містить 4 контентні сторінки, контакти та сторінку помилки 404).
4. **Інтеграція JS:** Написання скриптів для забезпечення динамічності та інтерактивності вебу.
5. **Фінальний деплой:** Валідація коду, усунення помилок у DevTools та публікація на GitHub.

---

## 💻 Використаний інструментарій
* **HTML5:** Чиста семантична розмітка з використанням сучасних структурних тегів.
* **CSS3:** Гнучке позиціонування елементів за допомогою технологій **Flexbox** та **CSS Grid Layout**. Реалізовано плавні переходи (`transition`).
* **JavaScript (ES6+) & Libraries:** Написання кастомних скриптів для DOM-маніпуляцій + підключення плагіну **Swiper.js** для каруселі відгуків.

---

## ⚡ Ключовий функціонал проєкту

Веб-сайт розроблено відповідно до вимог високого рівня складності та містить такі інтерактивні блоки:
* 🍔 **Навігаційне бургер-меню:** Оптимізоване під мобільні екрани меню з плавним зафарбовуванням шапки хедера та блокуванням прозорих накладань.
* 📊 **Динамічний рендеринг заходів:** Інформаційні картки весільної програми генеруються на льоту з масиву об'єктів у JS за допомогою методів роботи з DOM.
* ⏳ **Таймер зворотного відліку:** Інтерактивний лічильник часу до початку події з автоматичним форматуванням чисел (додавання нуля для одноцифрових значень).
* 🔄 **Анімована статистика:** Лічильники з числовими показниками, які запускають анімацію приросту значень при потраплянні блоку в зону видимості користувача.
* 🎬 **Мультимедійне модальне вікно:** Спливаюче вікно для перегляду відео з YouTube, яке автоматично скидає та зупиняє відтворення плеєра при закритті вікна ("miss click" захист).
* 🗂️ **Адаптивна галерея:** Сітка зображень, побудована на CSS Grid, із ефектом плавного збільшення фото та появою оверлею при наведенні.
* 📝 **Форми з валідацією:** Інпути для RSVP-підтвердження та зворотного зв'язку захищені від пустих відправлень (`required`) та мають правильну семантичну атрибуцію `name` для усунення варнінгів DevTools.

---

## 📐 Адаптивна сітка ( breakpoints )
Коректне відображення інтерфейсу забезпечено завдяки медіа-запитам для таких категорій пристроїв:
* Мобільні девайси: `до 767px` (з переходом елементів таймера в компактні круги)
* Планшетні ПК: `768px - 991px` (перебудова сітки галереї та приховування десктопного меню)
* Великі екрани та монітори: `992px і вище` (повнорозмірне відображення карток та блоків хедера)
