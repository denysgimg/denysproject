# Весільний веб-сайт "Геннадій & Жасмин"

Курсовий проєкт з розробки веб-інтерфейсів студента 3-го курсу спеціальності 126 "Інформаційні системи та технології".

## Функціонал

* **Багатосторінкова адаптивна верстка:** сайт оптимізовано та розбито на 4 контентні сторінки (`index`, `story`, `program`, `gallery`), а також окремі сторінки контактів та помилки 404. Коректно відображається на мобільних пристроях, планшетах та ПК.
* **Динамічний вивід елементів:** весільні заходи на сторінці програми завантажуються та рендеряться динамічно з масиву об'єктів за допомогою JavaScript (DOM Manipulation).
* **Інтерактивні лічильники:** реалізовано таймер зворотного відліку до дня весілля та лічильники статистики, які анімуються при скролі сторінки до блоку.
* **Інтерфейс та навігація:** розроблено зручне мобільне меню ("burger menu") та інтегровано слайдер побажань від друзів на базі Swiper.js.
* **Модальні вікна:** реалізовано форму підтвердження участі з функціоналом захисту від випадкового кліку поза вікном ("miss click") та спливаюче вікно для перегляду відео з YouTube.

## Технології

* HTML5, CSS3 (сітки Flexbox та Grid Layout)
* JavaScript (робота з DOM-структурою, масивами та подіями)
* Бібліотека Swiper.js (для каруселі відгуків)
* GitHub Pages для хостингу та публікації проєкту
